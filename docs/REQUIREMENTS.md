# 需求声明（Requirements）

> 项目代号：**Lyra**（暂定，可随时改名）
> 文档版本：v0.1 · 2026-10-17
> 配套文档：[`TECH_SPEC.md`](./TECH_SPEC.md)（技术要求）、[`PLAN.md`](./PLAN.md)（施工方案）、[`PLATFORM_SUPPORT.md`](./PLATFORM_SUPPORT.md)（平台与版本支持清单）

## 1. 背景与目标

手机上的本地音乐播放器要么界面过时，要么广告和多余功能太多。本项目要做一个**纯本地、无广告、无联网、界面完全遵循 Material Design 3** 的音乐播放器，主要给开发者本人日常使用。

核心目标按重要程度排序：

1. **能稳定播放常见格式**，尤其是 FLAC 和 MP3。
2. **正确显示内嵌封面和歌词**，同时支持外挂 `.lrc`。
3. **界面好看**：Material 3、动态取色、沉浸式封面背景、手机和桌面都有合适的布局。
4. **后台播放**和系统媒体控制完整可用。
5. **基础调音**：10 段均衡器 + 预设。

对音质没有发烧级要求，"能正确解码、听起来正常"即可。

## 2. 目标平台

详见 [`PLATFORM_SUPPORT.md`](./PLATFORM_SUPPORT.md)。**优先适配 macOS、Android、iOS；次级适配 Windows、Linux；明确拒绝适配 HarmonyOS。**

| 优先级 | 平台 | 支持基线 | 架构 | 说明 |
|---|---|---|---|---|
| 优先 | **Android** | Android 12 (API 31) | `armv8-a` | 手机为主，兼顾平板布局 |
| 优先 | **macOS** | macOS Sequoia (15.0) | `Intel` / `arm64` | 桌面窗口应用 |
| 优先 | **iOS** | iOS 18 | `arm64` | 移动应用 |
| 次级 | **Windows** | Windows 10 | `x64` / `arm64` | 桌面窗口应用 |
| 次级 | **Linux** | Ubuntu 22.04 | `x64` / `aarch64` | 桌面窗口应用 |
| **拒绝** | **HarmonyOS** | — | — | 明确不适配（Flutter 无官方 ohos，`cpal` 无 OHAudio 后端） |
| 不做 | Web | — | — | 不做适配 |

## 3. 非目标（明确不做）

- 在线音乐、流媒体、网络电台、在线歌词/封面刮削。
- 标签编辑（v1 不做，以后可能作为 P2+ 考虑）。
- 视频播放。
- Bit-perfect 输出、USB DAC 独占、重采样器选择等发烧功能。
- 账号、云同步、统计上报。应用**不应发起任何网络请求**。

## 4. 优先级定义

- **P0**：MVP 必须有，没有就不能日常用。
- **P1**：第一个"正式版"要有。
- **P2**：锦上添花，有空再做。

## 4.1 范围调整（2026-10-17，开发者确认）

开发者的曲库**只有 FLAC 和 MP3，歌词与封面全部内嵌**。据此调整优先级（需求本身保留，只是推迟）：

- 格式：FMT-03（AAC/M4A）、FMT-04（OGG/Opus/WAV）、FMT-05 由 P0/P1 降为 **P2**；MVP 只要求 FLAC 与 MP3。
- 外挂文件：LRC-02（外挂 `.lrc`）、LRC-03（来源优先级）、LRC-09（`.lrc` 编码识别）、META-03（文件夹封面回退）降为 **P2**。
- 双语歌词（LRC-08）由 P1 升为 **P0**：开发者曲库中已有同时间戳“原文 + 翻译”的歌词（实测样本见 PLAN M0-9）。
- 歌词只读内嵌来源（LRC-01）。`LyricsLoader` 仍保留多来源结构，以便以后补外挂。

| NFR-02 | **启动**：冷启动到可交互 ≤ 2 秒（曲库已建立的情况下） |
| NFR-03 | **流畅度**：滚动和动画在 Release 模式下保持 60fps，无明显掉帧 |
| NFR-04 | **内存**：浏览大曲库时不把原尺寸封面全部载入内存，使用缩略图缓存 |
| NFR-05 | **稳定性**：损坏文件、缺失文件、权限被收回时不崩溃，给出提示 |
| NFR-06 | **隐私**：不联网、不收集任何数据；只申请播放、通知、存储相关的必要权限，原则上不声明 `INTERNET`（若依赖库实测必须声明，在 `TECH_SPEC.md` 中说明原因） |
| NFR-07 | **耗电**：暂停状态下不持续占用 CPU；后台播放时界面相关的定时器全部停止 |
| NFR-08 | **可维护性**：分层清晰，核心逻辑（LRC 解析、EQ 参数生成、扫描比对、队列逻辑）有单元测试 |

## 7. MVP 定义

**MVP = 所有 P0 需求**。达到后应能替代开发者当前手机上的播放器日常使用。

## 8. 验收标准（MVP）

准备一个测试曲库（见 `PLAN.md` 附录），在 Android 真机和 macOS 上逐项验证：

1. 测试曲库中所有 P0 格式均能播放，损坏文件被跳过且有提示。
2. 中文、日文、英文标签显示正确；内嵌封面全部显示。
3. 内嵌歌词与外挂 `.lrc` 均能显示并同步滚动，点击歌词可跳转。
4. Android 锁屏 30 分钟持续播放不中断；通知栏、蓝牙耳机按键可控；来电自动暂停；拔耳机自动暂停。
5. macOS 关闭窗口后继续播放；媒体键与控制中心可控。
6. EQ 调节在两个平台上可听出相同变化，重启后设置保持。
7. 杀掉应用重启后恢复上次队列和位置。
8. 浅色/深色、系统配色、固定主题色及封面模糊背景均正常；手机竖屏、平板/宽窗口布局正确。
9. 5,000 首规模曲库（可用复制文件模拟）满足 NFR-01 ~ NFR-03。
